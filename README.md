Niko Autogaz — Уебсайт (статичен)
=================================

Описание
--------
Това е статичен уебсайт/лендинг за проекта nikoautogaz.github.io.

Структура на проекта
--------------------
- index.html — основна страница
- remont-fabrichen-metan-sofia.html — допълнителна съдържателна страница
- robots.txt — правила за търсачки
- sitemap.xml — карта на сайта
- images/ — папка със снимки и графики

Как да използвате
------------------
- Локално: отворете index.html в браузър.
- Деплой: подходящ за GitHub Pages или друг статичен хостинг — качете файловете в основната директория на сървъра/репото.
